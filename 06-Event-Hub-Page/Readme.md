# Event Hub

A simple **HTML event webpage** created to practice semantic HTML and page navigation.

---

## Project Overview

Event Hub is a basic webpage that displays **upcoming events** and **past events** with descriptions, dates, and images.

---

## What I Practiced

* HTML page structure
* Navigation using anchor links
* Semantic elements like `<header>`, `<nav>`, `<main>`, `<section>`, and `<article>`
* Adding images with `<img>`
* Using headings and paragraphs
* Creating separate sections for upcoming and past events

---

**HTML5**
