# freeCodeCamp Survey Form

A basic **HTML survey form** created to practice form elements and user input.

---

## Overview

This project is a survey form inspired by the **freeCodeCamp Survey Form** project. It collects basic information and feedback from users.

---

## Form Sections

* Name, email, and age
* Current role selection
* Recommendation options
* Favorite freeCodeCamp feature
* Improvement suggestions
* Comments and suggestions
* Submit button

---

## HTML Concepts

This project helped me practice:

* Labels and input fields
* Text, email, and number inputs
* Radio buttons
* Checkboxes
* Dropdown menus
* Textarea
* Form buttons
* Required fields

---

## Built With

**HTML5**

---

## Purpose

Created as part of my **HTML learning and practice** to understand how different form controls work together to collect user information.
