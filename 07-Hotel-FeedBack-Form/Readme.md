# Hotel Feedback Form

A simple **HTML feedback form** created to practice forms, input fields, and user interaction.

---

## About

This project allows hotel guests to provide feedback about their stay by entering personal information, answering questions, selecting ratings, and adding comments.

---

## Form Includes

* Personal information
* First-time visitor radio buttons
* Multiple-choice checkboxes
* Service and food ratings
* Additional comments
* Submit button

---

## HTML Concepts Used

`<form>` · `<fieldset>` · `<legend>` · `<label>` · `<input>` · `<select>` · `<option>` · `<textarea>` · `<button>`
