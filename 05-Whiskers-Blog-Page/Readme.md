# Mr. Whiskers' Blog

A simple **HTML blog page** created to practice basic HTML and semantic HTML elements.

---

## Features

* Header and navigation menu
* Cat image with figure and caption
* About section
* Blog posts using `<article>`
* Contact section
* Phone and email links
* Semantic HTML elements such as:

  * `<header>`
  * `<nav>`
  * `<main>`
  * `<section>`
  * `<article>`
  * `<footer>`
  * `<address>`

---

## Purpose

This project was created as part of my **HTML learning and practice**, focusing on page structure and semantic HTML.
